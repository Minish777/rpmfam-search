# rpmfam-search

Поиск по списку зарегистрированных фамилий: зарегистрирована ли фамилия,
кто представитель, кто заместитель, с номерами паспортов и телефонами.

В Google Docs фамилии в одном месте, а люди расписаны по сноскам в конце
документа — искать неудобно. Утилита делает это одной командой.

> Написано с помощью ИИ, баги возможны. [Как сообщить о баге](#баги)

## Установка

Python 3.8+, зависимостей нет.

**Linux / macOS**

```bash
git clone https://github.com/Minish777/rpmfam-search.git
cd rpmfam-search
pip install --user .        # команда rpmfam-search станет доступна везде
```

**Windows** (PowerShell)

```powershell
git clone https://github.com/Minish777/rpmfam-search.git
cd rpmfam-search
py -m pip install --user .
```

После установки команда работает из любого каталога — `rpmfam-search Амброус`
в PowerShell, cmd или Git Bash.

Без установки, прямо из папки проекта:

```bash
python rpmfam_search.py Амброус        # Windows: py rpmfam_search.py Амброус
python -m rpmfam_search Амброус
```

Первый запуск потребует выбрать документ с фамилиями — см.
[Первый запуск](#первый-запуск).

## Первый запуск

При первом запуске утилита спросит, из какого документа читать фамилии:

```
Первый запуск — нужно выбрать документ с фамилиями.

Вставьте ссылку или ID документа: 
```

Пропустить нельзя. Пока документ не выбран, не работает ни одна команда —
кроме `-h`, `--doc` и `--clean`. Выбор сохраняется, спрашивают один раз.

Документ должен быть доступен **всем, у кого есть ссылка**: в Google Docs
откройте «Доступ» и поставьте «Читатель для всех, у кого есть ссылка».
Утилита читает его анонимно, без входа в аккаунт.

Принимается и полная ссылка, и голый ID:

```
https://docs.google.com/document/d/1a_7a…/edit?pli=1
1a_7aQdGgEZadPHEW7WEq8rIaWDm2lcx4mXs7W-PzAwA
```

Документ сразу проверяется: если это не реестр фамилий, утилита скажет
почему и попросит другую ссылку.

Сменить документ позже — `rpmfam-search --doc <ссылка> --name "Фамы Юга"`.

## Использование

```bash
rpmfam-search Амброус      # по фамилии, можно часть: Амб
rpmfam-search sqW1nz       # по нику представителя
rpmfam-search "Григорий"   # по имени
rpmfam-search 910442       # по номеру паспорта или телефона
rpmfam-search Кингсманн    # опечатка -> покажет похожие
rpmfam-search              # новые фамилии за неделю
rpmfam-search --all        # весь список по алфавиту
```

```
Зарегестрированная фамилия: "Амброус"
  Представитель: "Винс Амброус (sqW1nz)"  RPM-910442 | тел. 14882930
  Заместитель: "Лиллит Амброус (mosya_ma)"  RPM-952095 | тел. 75553537

──────────────────────────────────────────────
Данные актуальны на 26.09.2026 16:48
источник: RPM North
```

Остальные ключи — `-c` только представитель, `-r` обновить кеш, `-s N` за
сколько дней искать новые, `--check` проверить данные, `--clean` удалить кеш.
Полный список: `rpmfam-search -h`.

## Знаки

| | |
|---|---|
| `*` | подойдёт любой представитель фамилии, уточни у Главы заранее |
| `⚠` | предупреждение из документа |
| `⛔` | битая ссылка «относится к фамилии» — правьте у автора документа |
| `→` | фамилия привязана к другой, представители показаны оттуда |

## Свой документ

См. [Первый запуск](#первый-запуск) — документ выбирается один раз при
установке. Потом:

```bash
rpmfam-search --doc                    # что подключено сейчас
rpmfam-search --doc <ссылка> --name X  # переключить на другой
rpmfam-search --doc reset              # отключить, потом снова спросит
```

## Как это работает

Текст документа забирается через публичную ссылку экспорта Google Docs
(`export?format=txt`) и кэшируется на 5 минут, дальше список обновляется сам.

**Утилита только читает документ** — не вносит изменений и никуда ничего не
отправляет. На диске держит два файла: кеш и историю появления фамилий,
права `600`. Всё это удаляется через `--clean`.

## Баги

Открыть issue: https://github.com/Minish777/rpmfam-search/issues/new

Форма сама спросит, что делали, что ожидали и что получили. Заполни её — это
самый быстрый способ, чтобы разобраться без лишних переписок. Полезно
приложить вывод `rpmfam-search --check`.

Так выглядит нормальное описание:

```
Что делали:      rpmfam-search Аккерман
Ожидал:          строку «Представитель» с номером паспорта
Получил:         «нет данных в документе», фамилия находится в --all

Через пару дней фамилия пропала из выдачи совсем, хотя документ не меняли.
Та же фамилия через Ctrl+F в документе находится.

Где:   Windows 11, PowerShell
Python: 3.12.4
Установка: py -m pip install --user .

Вывод --check:
  Проверка целостности данных
    фамилий:               224
    сносок в документе:    230
    привязано к фамилиям:  228
```

Главное — написать **что делали, что ждал и что получил**. По этим трём
строкам обычно сразу понятно, где чинить, без уточняющих вопросов.

Можно написать и напрямую: **systemd** в Discord. Pull request приветствуются.

## Тесты

```bash
python -m unittest discover -s tests
```

Работают на синтетическом документе из `fixtures/sample.txt`, сеть не нужна.
В фикстуре воспроизведены грабли из живого документа: лишние и незакрытые
скобки, буллиты вместо строк, склейка абзацев, телефон без пробела после тире.
