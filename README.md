# rpmfam-search

Поиск по списку зарегистрированных фамилий: сразу видно, зарегистрирована ли
фамилия, кто её представитель и кто заместитель, с номерами паспортов и
телефонами.

В Google Docs нет нормального поиска по такому списку — фамилия в одном
месте, а люди расписаны по сноскам в конце документа. Утилита делает это за
одну команду в терминале.

> **Проект написан с помощью ИИ.** В нём почти наверняка есть ошибки.
> Парсер держится на регулярных выражениях и работает с живым документом,
> который редактируют вручную. Если что-то работает не так — [сообщите об
> этом](#нашли-баг), починим.

## Установка

Нужен Python 3.8 или новее. Никаких зависимостей.

```bash
git clone https://github.com/Minish777/rpmfam-search.git
cd rpmfam-search
python3 rpmfam_search.py Амброус          # запустить без установки
```

Чтобы команда `rpmfam-search` была доступна глобально:

```bash
pip install .
```

Или просто symlink, без установки:

```bash
ln -s "$PWD/rpmfam_search.py" ~/.local/bin/rpmfam-search
chmod +x rpmfam_search.py
```

Работает на Linux, macOS и Windows.

## Использование

```bash
rpmfam-search Амброус           # по фамилии
rpmfam-search Амб               # частичное совпадение
rpmfam-search sqW1nz            # по нику представителя
rpmfam-search "Григорий"        # по имени
rpmfam-search 910442            # по номеру паспорта
rpmfam-search 14882930          # по телефону
rpmfam-search Кингсманн         # опечатка -> покажет похожие
rpmfam-search                   # новые фамилии за неделю
rpmfam-search --all             # весь список по алфавиту
```

Пример вывода:

```
Зарегестрированная фамилия: "Амброус"
  Представитель: "Винс Амброус (sqW1nz)"  RPM-910442 | тел. 14882930
  Заместитель: "Лиллит Амброус (mosya_ma)"  RPM-952095 | тел. 75553537

──────────────────────────────────────────────
Данные актуальны на 26.09.2026 16:28
источник: RPM North
Документ обновлён: 12.09.2026 (Григорий Ваховски)
```

### Ключи

| Ключ | Значение |
|---|---|
| `-a`, `--all` | список всех фамилий по алфавиту |
| `-c`, `--contacts` | искать только по представителю, не по фамилии |
| `-r`, `--refresh` | обновить данные, игнорируя кеш |
| `-s`, `--since ДНЕЙ` | за сколько дней искать новые фамилии (по умолчанию 7, `0` — только с прошлого запуска) |
| `--check` | проверить, что данные разобрались без потерь |
| `--doc` | показать, подключить или сбросить документ |
| `--clean` | удалить кеш, историю и настройки |
| `--no-color` | без цветов |

### Пометки в выводе

| Пометка | Что значит |
|---|---|
| `* подойдёт любой представитель` | условия выдачи отличаются, уточняй у Главы заранее |
| `⚠` | предупреждение из самого документа |
| `Двойные фамилии того же человека` | у человека две фамилии, он значится в обеих |
| `→ относится к фамилии` | фамилия привязана к другой, представители показаны оттуда |

### Свой документ

По умолчанию подключён документ RPM North. Чтобы работать со своим реестром
фамилий (другой отдел, свой регион):

```bash
rpmfam-search --doc "https://docs.google.com/document/d/<ID>/edit?pli=1" --name "Фамы Юга"
```

Утилита скачает документ, проверит, что он действительно похож на реестр
фамилий (иначе откажется подключать), и запомнит выбор в конфиге — вводить
ссылку повторно не придётся.

```bash
rpmfam-search --doc           # что подключено сейчас
rpmfam-search --doc reset     # вернуть встроенный документ
```

Документ должен быть доступен **любому, у кого есть ссылка** — «Просмотр для
всех, у кого есть ссылка». Утилита читает документ анонимно, без входа в
аккаунт, поэтому закрытый документ не сработает.

## Как это работает

Утилита забирает текст документа через публичную ссылку экспорта
(`export?format=txt`), разбирает список фамилий и сноски к ним, и показывает
найденное. Данные кэшируются на 5 минут, дальше список обновляется сам.

**Утилита только читает документ.** Она не вносит в него никаких изменений и
никуда не отправляет данные — запрос анонимный, примерно такой же, как если
бы вы открыли ссылку в браузере.

На диске она держит два файла: кеш выгрузки и историю появления фамилий
(нужна, чтобы показывать новые). Права на них — `600`, только для вас.
Всё это удаляется командой `rpmfam-search --clean`.

## Нашли баг

Самый быстрый способ — [открыть issue](https://github.com/Minish777/rpmfam-search/issues/new).
При создании GitHub покажет форму, там есть несколько вопросов — **чем
подробнее ответите, тем быстрее разберёмся**. Особенно полезно, если приложить
вывод `rpmfam-search --check` и то, что выводила утилита вместо ожидаемого.

Можно и написать напрямую в Discord: **systemd**

Пример хорошего описания:

```
Что делал:      rpmfam-search Амброус
Что ожидал:     две строки, представитель и заместитель
Что получил:    «Фамилия "Амброус" не зарегистрирована», подсказка «Амброуз»
Версия:         Python 3.12, Linux
Вывод --check:  (приложить)
```

Присылайте и pull request — изменения приветствуются.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты работают на синтетическом документе из `fixtures/sample.txt`, сеть не
нужна. В фикстуре специально воспроизведены грабли из живого документа:
лишние и незакрытые скобки, буллиты вместо строк, склейка абзацев, телефоны
без пробела после тире.
